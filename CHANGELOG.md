# Changelog

## 0.1.0 — 2026-11-23

First public release.

- Local library (MP3/FLAC/OGG/M4A), ID3v1/v2, whole-SD scanner.
- SoundCloud search, playlists, account/playlist URLs, private playlists via OAuth token.
- Progressive MP3 and HLS/AAC playback + offline cache.
- SOCKS5/HTTP proxy support with direct fallback.
- RU/EN UI (English by default), gamepad + touch controls, shuffle, likes, downloads.
- Fixed audout lifecycle, multi-buffer playback, HLS init parsing, text relocations.
